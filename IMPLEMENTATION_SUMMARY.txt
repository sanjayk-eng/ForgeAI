🔄 User Flows:

1. Send Invite:
   - Admin clicks "Invite member"
   - Enters email + role
   - Backend creates invite with token
   - Email sent with link: /accept-invite/:token

2. Accept Invite (New User):
   - Clicks link → AcceptInvitePage
   - Not logged in → Shows "Sign in" or "Create account"
   - After login → Auto-redirects back
   - Email matches → Accept button
   - Joins workspace

3. Accept Invite (Existing User):
   - Clicks link → Already logged in
   - Email matches → Shows accept/decline
   - Clicks accept → Added to workspace
   - Redirects to workspace

4. Revoke Invite:
   - Admin goes to Members → Invitations tab
   - Pending invites show "Revoke" button
   - Click revoke → Invite status = REVOKED
   - User can no longer accept
